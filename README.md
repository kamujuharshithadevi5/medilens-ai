# 🩺 MediLens AI

> AI-Powered Healthcare Report Assistance Platform

MediLens AI is a web-based healthcare report assistance platform designed to help users organize, understand, and analyze medical reports through an easy-to-use interface.

The platform provides structured report information, AI-generated explanations, health alerts, analytics, and report management features.

⚠️ Medical Disclaimer:
MediLens AI provides AI-generated informational explanations and is not a medical diagnosis system. It does not replace professional medical consultation.

## 🔌 Backend API

The FastAPI backend provides REST API endpoints for application functionality.

Example endpoints:

GET    /api/health
GET    /api/reports
POST   /api/reports
GET    /api/reports/{report_id}
DELETE /api/reports/{report_id}
POST   /api/reports/{report_id}/analyze
GET    /api/alerts
POST   /api/alerts/{alert_id}/read
POST   /api/alerts/read-all
GET    /api/analytics


## 💻 Run Locally

### 1. Clone the Repository

git clone https://github.com/kamujuharshithadevi5/medilens-ai.git

cd medilens-ai


### 2. Run the Backend

cd backend

pip install -r requirements.txt

uvicorn main:app --reload

Backend:

http://127.0.0.1:8000


### 3. Run the Frontend

Open another terminal:

cd frontend

npm install

npm run dev

Frontend:

http://localhost:5173
